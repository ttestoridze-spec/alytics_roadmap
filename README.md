# Roadmap Alytics

Интерактивный роадмап для управления задачами проекта с визуализацией на временной шкале.

## 🚀 Основные возможности

### 📅 Временная шкала с Paging
- **Видимый период** — по умолчанию отображается ~3 месяца
- **Колёсико мыши** — прокрутка по временной шкале (смена видимого периода)
- **Shift + колёсико** — пошаговая прокрутка по 1 дню
- **Кнопки навигации** — "Назад" / "Вперёд" для перехода между периодами
- **Быстрый зум** — кнопки 1М / 3М / 6М / 1Г для быстрого переключения масштаба
- **Drag & Drop карточек** — перемещение задач на шкале
- **Resize** — изменение длительности перетаскиванием за края

### 📋 Список задач с Drag & Drop
- **Группировка** — по приоритету, дате начала, типу, статусу или без группировки
- **Перетаскивание** — меняйте порядок задач для приоритизации
- **Визуальные индикаторы** — цветная полоска приоритета слева

### 🎴 Карточки с атрибутами
- Название и описание
- Тип (Backend, Frontend, DevOps, Инфра, V3 Alytics, Техдолг и др.)
- Группа (эпик/направление)
- Объём (часы/дни/недели/story points)
- **Авторасчёт размера** — карточка растягивается по объёму
- Ссылка на Jira
- Ответственный
- Статус и приоритет

### ⚙️ Настройки
- Типы карточек с цветами и иконками
- Список ответственных с ролями
- Группы для организации задач

### 💾 Управление данными
- Экспорт в JSON
- Импорт из JSON
- Автоматическое сохранение в localStorage

## 📦 Локальная разработка

### Установка на Windows (WSL)

```bash
# В Ubuntu WSL:
sudo apt update && sudo apt upgrade -y
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs git

# Клонирование
cd ~ && mkdir -p projects && cd projects
git clone https://github.com/ttestoridze-spec/alytics.git
cd alytics
npm install

# Запуск
npm run dev
# Откроется на http://localhost:5173
```

## 🎯 Как использовать

### Навигация по временной шкале
1. **Колёсико мыши** на шкале — переключение периода
2. **Shift + колёсико** — точная прокрутка по дням
3. **Кнопки ← →** — переход на период вперёд/назад
4. **Кнопки 1М/3М/6М/1Г** — быстрый зум

### Перетаскивание задач в списке
1. Выберите группировку (по приоритету, дате и т.д.)
2. Зажмите карточку и перетащите вверх/вниз
3. Отпустите на новом месте — порядок сохранится

### Создание карточки
1. Нажмите "+ Новая карточка"
2. Заполните поля
3. Включите "📐 Авторасчёт размера" — карточка растянется по объёму
4. Сохраните
